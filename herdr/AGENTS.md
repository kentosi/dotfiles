# AGENTS.md

This file provides guidance to AI coding agents when working with code in this repository.

## What this is

Config for the `herdr` tool: `config.toml` sets onboarding, theme, and UI/toast behavior. `.plugins.lock` is a lockfile, in the same spirit as `nvim/lazy-lock.json` — regenerated by the tool itself, not hand-edited.

## Tracked vs. local-only files

This directory also holds files the tool writes at runtime that are deliberately **not** tracked (see the root `.gitignore`): `*.log`, `session.json`, `release-notes.json`. They may be present locally but should never be added to git or edited as if they were config — only `config.toml` and `.plugins.lock` are the actual tracked configuration.
